Install Dizko Events

Live event discovery (concerts, club nights, art, comedy, festivals) for any AI assistant that speaks MCP. No account, no API key.

Recommended: add the hosted connector no install

✓ Runs on our servers — it never gets access to your computer or files, so you won’t see a scary local-install warning.

Copy the endpoint (click to select):

https://mcp.dizko.app/mcp
  1. In Claude (claude.ai or Claude Desktop), open Settings → Connectors (web: click your initials, bottom-left).
  2. Click Add custom connector.
  3. Name it Dizko Events and paste the endpoint URL. No auth needed.
  4. In any chat, enable it from the tools menu and ask: “What’s happening in Los Angeles this weekend?”

Custom connectors require a paid Claude plan. When the tool-permission prompt appears, choose “Always allow” — you’re only asked once per tool. (ChatGPT: Settings → Apps & Connectors → Advanced → Developer mode → add the same URL.)

Claude Code

claude mcp add --transport http dizko-events https://mcp.dizko.app/mcp

Cursor

Add the hosted endpoint to ~/.cursor/mcp.json:

{
  "mcpServers": {
    "dizko-events": {
      "url": "https://mcp.dizko.app/mcp"
    }
  }
}
Advanced: run the server locally

Only needed if you can’t use the hosted connector (e.g. a free Claude plan, or a client that only supports local servers). A local server runs on your machine, so Claude Desktop shows a warning that the extension “can access everything on your computer.” That’s true of any local MCP extension — there’s no narrower permission to grant; the program runs as you. The hosted connector above avoids this entirely because nothing runs locally. The code is open source and the server only ever calls the Dizko events API.

Claude Desktop one-click bundle

Download the .mcpb extension and double-click it (or drag it into Claude Desktop → Settings → Extensions). No terminal; Claude Desktop runs it with its built-in runtime.

Any MCP client (stdio config)

Requires Node 20+:

{
  "mcpServers": {
    "dizko-events": {
      "command": "npx",
      "args": ["-y", "uplayground-events", "mcp"]
    }
  }
}

One-line installer

Writes the config for you — claude-desktop, cursor, or claude-code:

npx -y uplayground-events install claude-desktop

Try it from a terminal (no MCP client needed)

npx -y uplayground-events search --city "los angeles" --when "this week"

Something not working? Run npx -y uplayground-events doctor for a connectivity report.
