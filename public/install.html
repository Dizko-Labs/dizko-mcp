Install UPlayground Events

Live event discovery (concerts, club nights, art, comedy, festivals) for any AI assistant that speaks MCP. No account, no API key.

The hosted endpoint — click a code block to select it, then copy:

https://eventchat-events-mcp-production.up.railway.app/mcp

Claude (claude.ai or Claude Desktop) — recommended

  1. Open Settings → Connectors (web: click your initials, bottom-left).
  2. Click Add custom connector.
  3. Name it UPlayground Events and paste the endpoint URL above. No auth needed.
  4. In any chat, open the tools menu and make sure the connector is enabled, then ask: “What’s happening in Los Angeles this weekend?”

Custom connectors require a paid Claude plan. When the tool-permission prompt appears, choose “Always allow” — you will only be asked once per tool.

Claude Desktop — one-click bundle

Download the .mcpb extension, then double-click it (or drag it into Claude Desktop → Settings → Extensions). No terminal, no config files, no Node install — Claude Desktop runs it with its built-in runtime.

Claude Code

claude mcp add --transport http uplayground-events https://eventchat-events-mcp-production.up.railway.app/mcp

ChatGPT (developer mode)

  1. Open Settings → Apps & Connectors → Advanced → Developer mode.
  2. Add a connector with the endpoint URL above (no authentication).

Cursor

Add to ~/.cursor/mcp.json (or use the one-line installer below):

{
  "mcpServers": {
    "uplayground-events": {
      "url": "https://eventchat-events-mcp-production.up.railway.app/mcp"
    }
  }
}

Any other MCP client (local stdio server)

Requires Node 20+. Add to your client’s MCP config:

{
  "mcpServers": {
    "uplayground-events": {
      "command": "npx",
      "args": ["-y", "uplayground-events", "mcp"]
    }
  }
}

One-line installer (terminal)

Writes the config for you — supports claude-desktop, cursor, claude-code:

npx -y uplayground-events install claude-desktop

Try it from a terminal (no MCP client needed)

npx -y uplayground-events search --city "los angeles" --when "this week"

Something not working? Run npx -y uplayground-events doctor for a connectivity report.
