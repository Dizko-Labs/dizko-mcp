Support

Need help with the Dizko Events connector?

Common Requests

  • Ask the assistant to find events in a city, for a date, or by genre, vibe, venue, artist, or budget.
  • Ask the assistant to remember your event preferences only if you want personalized recommendations over time.
  • Ask the assistant to delete your saved event preferences and feedback history if you want personalization removed.

Security And Vulnerability Reports

If you believe you found a vulnerability in the connector, profile-secret access, preference deletion, or event API behavior, email security@dizko.app. Please include the MCP endpoint, affected tool name, steps to reproduce, and whether any user data may be involved. Do not include another person's profile secret or private data in the report.

Contact

Email support@dizko.app for support, bug reports, or account/privacy help.
